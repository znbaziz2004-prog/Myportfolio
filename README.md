# Zainab Aziz — Portfolio

Personal portfolio site built with React, Vite, and Tailwind CSS.

## Sections

- **Hero** — introduction and quick links (CV, GitHub, LinkedIn, email)
- **About** — background, education, and focus areas
- **Skills** — languages, frameworks, and tools
- **Projects** — selected work, including the information security and AI-authenticity projects
- **Contact** — contact form and direct details

## Getting started

```bash
npm install
npm run dev
```

Open the local URL Vite prints in your terminal.

## Build for production

```bash
npm run build
```

Outputs a production build to `dist/`.

## Before publishing

- Replace the placeholder `github` (and optional `demo`) links in `src/components/Projects.jsx` with your real project URLs.

## Tech stack

React 19 · Vite · Tailwind CSS v4 · react-icons · react-type-animation
